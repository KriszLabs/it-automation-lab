Ez a repository azokat a projekteket gyűjti össze, amelyeken a mindennapi munkám során szerzett tapasztalatokra építve dolgozom.

Többségük Microsoft 365 adminisztráció, Windows üzemeltetés vagy ezekhez kapcsolódó dokumentáció, valamint PowerShell automatizálás.

A célom nem a demóprojektek létrehozása, hanem olyan eszközök vagy megoldások, amelyek egy valós IT-környezetben is használhatók vagy továbbfejleszthetőek.

Rólam:

Nyilas Kristóf vagyok, 4 éve Rendszergazdaként dolgozom a Semmelweis Egyetemen.
